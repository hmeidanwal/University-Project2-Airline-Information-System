# PRJ2 - Airline Information System

This flight ticket sales application was developed as a **group project at Fontys University of Applied Sciences** for Project 2.
The application supports the sales and management of flight tickets. Flight officers can register upcoming flights and configure temporary discounts, while sales employees can create trips and bookings for one or more passengers. Ticket prices are calculated based on factors such as travel class, seat availability, discounts, and additional options including extra legroom, food, luggage, and seat selection. The application also includes a **management dashboard** displaying information such as revenue, tickets sold per class, and statistics about purchased options.

## How to run the application
- To start the backend
   * Start the terminal in VS Code or the Windows PowerShell as an administration
   *Type *cd location of assmebler* (for example: cd User/.../Documents/Github/implementation/backend/assembler)
   *Type *mvn exec:java*

- To start the frontend
   * Start A SEPARATE terminal in VS Code or the Windows PowerShell as an administration
   * Type *cd location of frontend* (for example: cd User/.../Documents/Github/implementation/frontend)
   * Type *npm run dev*
