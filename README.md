## How to run the application
- To start the backend
   * Start the terminal in VS Code or the Windows PowerShell as an administration
   *Type *cd location of assmebler* (for example: cd User/.../Documents/Github/implementation/backend/assembler)
   *Type *mvn exec:java*

- To start the frontend
   * Start A SEPARATE terminal in VS Code or the Windows PowerShell as an administration
   * Type *cd location of frontend* (for example: cd User/.../Documents/Github/implementation/frontend)
   * Type *npm run dev*
